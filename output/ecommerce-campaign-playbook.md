# 电商大促策划与执行 Playbook（独立运营手册）

> **定位**：本文件是「怎么打一场大促」的经营执行 playbook，**不属于 research-kit 的研究/诊断方法**。它对应「已有目标、要协同落地」的执行方案体裁，与大促后的诊断复盘（见 `method-ecommerce-ops` 的 M6 / `campaign-diagnostic.md`）是前后两段、互不替代。
> **适用**：双11 / 618 / 双12 等节日大促的全周期策划与执行（T-60 至 T+7）。
> **本范例基线**：三平台（天猫/淘宝 · 京东 · 拼多多）× 家用快消；其余品类/平台可套用框架，填空位 `___` 按真实数据填。

---

## 一、目标与成功标准（KPI 红线）

| 维度 | 目标值 | 口径 |
|---|---|---|
| 三平台合计广告 ROAS | ≥ 3:1 | 含天猫直通车/万相台、京东京准通、拼多多全站 |
| 店铺评分 | ≥ 4.8 / 5.0 | 三平台分别维持 |
| 退货率 | < 5% | 家用快消标品，低退货即 listing 准确、品质稳 |
| 90 天复购率 | > 25% | 大促一次性客转长期复购客 |
| 直播 GMV 占比 | ≥ 20% | 淘宝直播 + 京东直播合计 |
| 类目排名 | 至少一平台 Top10 | 目标类目 |
| 净利率 | > 0 | 扣平台费/推广/物流/佣金后 |

**范围**：三平台大促全周期 + 家用快消品类。**范围外**：抖音、日常非促运营、非家用快消。
**硬约束**：① 净毛利低于红线 `___%` 的 SKU 不得进主推；② 价格与功效宣称合规；③ 库存零超卖；④ 物流时效写入详情页并履约。

> ⚠️ **毛利红线**：任何促销机制（定金膨胀 / 满减 / 品类券叠加）落地前，必须先跑毛利瀑布确认净毛利 ≥ 红线；拼多多可接受低毛利但须靠走量摊薄，净毛利不得为负。

## 二、三平台分工与定位

| 平台 | 战役角色 | 核心打法 | 货品重心 |
|---|---|---|---|
| 天猫/淘宝 | 品牌主场 + 会员复购 | 组合装/礼盒装 + 赠品 + 会员专享价；详情页精细化 | 利润款、形象款、新品 |
| 京东 | 标品信任 + 次日达 | 家庭装 + PLUS 专享 + 京东物流时效背书 | 标品正装、家庭装 |
| 拼多多 | 走量清仓 + 价格锚 | 单品爆款 + 百亿补贴对标 + 限时秒杀 | 引流款、清仓款 |

> 三平台算法/人群/费用结构完全不同，**严禁一套打法复制**；SKU 做平台独占以避免直接比价（拼多多低价会拖天猫价盘）。

## 三、货品矩阵与定价毛利架构

**四款矩阵**（配比 引流:利润:活动:形象 ≈ 2:4:3:1），SKU 四层：正装 / 家庭装 / 组合装 / 赠品。

| 款类 | 作用 | 家用快消示例 |
|---|---|---|
| 引流款 | 亏毛利换曝光，目标进店率 | 抽纸/垃圾袋单品 |
| 利润款 | 双11 主力利润，靠「单件更便宜」话术 | 组合装/家庭装/囤货装 |
| 活动款 | 满足满减门槛，冲销量排名 | 平台会场报名款 |
| 形象款 | 拉品牌调性，不冲量 | 新品/高端线 |

**定价机制**：预售定金膨胀（如 50 抵 80）→ 跨店满减（每满 300-50，平台承担部分）→ 品类券 → 店铺券 → 返场价。
**毛利瀑布（每款必算）**：出厂价 `___` → 平台扣点 `___%` → 推广费 `___%` → 物流 `___` → 达人/直播佣金 `___%` → 活动让利 `___` → 净利 `___`。

## 四、四大工作流

### 4.1 Listing 优化（标题/主图/详情页）
- **标题**：天猫=`[品牌]+[核心词]+[规格]+[卖点]+[场景]`（60字）；京东=`[品牌]+[品名]+[规格]+[场景]`（45字，重参数）；拼多多=`[核心词]+[价格锚]+[价值点]+[社会证明]`（60字）。
- **主图 5 slot**：①白底产品 ②核心卖点 ③使用场景 ④销量/认证 ⑤活动价+紧迫感。
- **详情页 8 段**：价值钩子→痛点场景→规格材质→间接对比→评价→使用说明→品牌信任→FAQ（保质期/正品/临期）。

> **作战示例（标题模板）**：
> - 天猫：`XX 抽纸 原生木浆 3层100抽 家庭装 24包 整箱 囤货`（品牌+核心词+规格+卖点+场景，吃搜索意图）
> - 京东：`XX 抽纸 24包家庭装 京东物流 次日达`（规格+时效背书，重参数与信任）
> - 拼多多：`抽纸 整箱24包 工厂直发 比超市省一半 已售10万+`（价格锚+价值点+社会证明前置）

### 4.2 付费投放
| 平台 | 工具 | 目标 ROAS | 主力用法 |
|---|---|---|---|
| 天猫/淘宝 | 直通车/万相台/超级推荐 | ≥ 3:1 | 直通车抢长尾词，万相台拉新快/货品加速 |
| 京东 | 京准通（快车/海投/触点） | ≥ 3:1 | 快车抢标品词，海投全店托管 |
| 拼多多 | 多多搜索/多多场景/全站 | ≥ 2:1 | 新品前14天激进出价，场景 retargeting |

**三阶段预算**：蓄水 40% → 爆发 45%（小时级调价）→ 返场 15%。**周循环**：周一复盘暂停劣者 → 周二至四测新词/人群/创意 → 周五调价 → 周末监控自动计划。

> **作战示例（投放配置）**：
> - 天猫：直通车「精准长尾词抢位 + 智能词包」控成本，万相台「拉新快 / 货品加速」拉新与爆发加速双计划分设。
> - 京东：快车「抢标品核心词高位」+ 海投「全店托管」兜底长尾，触点做老客召回。
> - 拼多多：新品前 14 天「多多搜索激进出价」抢排名，稳定后切「全站推广」控 ROI，场景做加购 retargeting。

### 4.3 直播带货
- 重投淘宝直播、京东直播；拼多多直播轻投入。
- 话术框架：演示清洁/去污效果 → 算「一天几毛钱」账 → 囤货装单价对比 → 限时库存逼单。
- 排期：预热期每日 2-4h 常态化播（蓄水加购）；爆发期 8-12h 马拉松（整点闪购 10:00/14:00/20:00/24:00）。

### 4.4 私域蓄水与会员留存
- 天猫会员/京东 PLUS 做预售早鸟价+专享赠品；拼多多无强会员 → 引导加企微私域。
- 蓄水期 CRM 触达 → 爆发期催付（未付定金/尾款）→ 返场期复购券+评价有礼。目标 90 天复购率 > `___%`。

## 五、依赖关系与关键路径

**关键路径（串行）**：货品定稿 → 毛利核算（过红线）→ 生产/采购下单 → 素材定稿 → 投放计划配置 → 平台报名 → 蓄水启动 → 爆发执行。
**可并行**：三平台 listing 同步；直播排期与素材并行；私域话术与投放计划并行。瓶颈在「生产/采购交期」与「素材定稿」，须最早启动。

## 六、里程碑与退出条件（T = 距爆发日天数）

- **T-60 战略**：定 GMV 目标倒推流量/转化；谈会场坑位；定货品矩阵与每 SKU 毛利；下采购单。`退出`：货品清单+毛利表+采购单齐备。
- **T-30 准备**：素材定稿；配预售/满减机制；建投放计划；直播 brief；客服扩容。`退出`：草稿态校验通过。
- **T-15 报名**：平台报名；优惠配置校验；库存锁定防超卖。`退出`：报名通过+计算器自检无误。
- **T-7 蓄水**：开预售收定金；投放加码；社媒种草；老客触达；竞品监控。`退出`：定金支付率 `___%`、加购 `___%`。
- **T-Day 爆发**：作战室（GMV/库存/客服看板）；小时级调价；直播马拉松；库存预警；整点闪购+战报。`退出`：当日 GMV 达 `___%`。
- **T+1~7 返场复盘**：战报 vs 目标；分渠道 ROI；退货处理；复购 campaign；团队复盘。

## 九、治理、变更与验收

- **节奏**：T-60/T-30/T-15/T-7 四次决策门；爆发期每日战报；返场期出复盘。
- **升级条件**：任一平台 ROAS 连续 3 日 < 目标 70%，或库存预警触发，立即升级总控。
- **变更**：货品/机制/预算变更须更新基线表并重新验收，禁止口头改价。
- **验收方**：GMV/ROAS 由投放与总控共验；毛利由货品/财务共验；合规由运营负责人签核。

## 十一、复盘模板（T+7 必做）

1. 战报：实际 vs 目标（分平台、分款类）。
2. 分渠道/分 SKU ROI 与毛利健康度（引流/利润占比）。
3. 直播贡献占比与单场转化（**须用退款后净 GMV**）。
4. 退货归因（保质期/描述不符/物流）。
5. 沉淀：3 条可复用经验 + 3 条下场改进，回写本 playbook 基线。

## 十二、预注册 Monitors（规划期固化，供 M6 回写）

> **闭环关键**：把第十节看板指标在规划期就固化为带阈值的 `monitors`，大促期间持续回填，大促后直接供 `method-ecommerce-ops` 的 M6 做诊断基线（异常指标回写 `research-state.yaml` 的 `monitors` 带阈值告警，满足防复发）。

| monitor | 阈值/告警线 | 口径 | 触发动作 | 回写归属 |

## 十三、规划→诊断交接（planning → M6 handoff）

> 本 playbook 负责"怎么打"（规划/执行），`method-ecommerce-ops` 的 M6 负责"打完怎么诊断"。衔接契约：

1. **目标即基线**：第六/十节定的 GMV、ROAS、毛利红线、复购率目标，即 M6 七步法第①步"战报 vs 目标"的对照基线——规划期不填实则 M6 无处对标。
2. **monitors 即证据链**：第十二节预注册的 monitors 在大促期间持续回填，成为 M6 各步"证据链"的数据源，避免 T+7 临时找数。
3. **口径即 G4 前置**：第十节的口径（退款后净 GMV、跨平台折算）须在规划期登记，满足 M6 / 主技能"关键口径 G4"门禁，否则诊断结论无效。
4. **复盘即回写**：本节 T+7 复盘产出的 3 经验/3 改进，回写本 playbook 基线 + M6 的 `monitors`，构成"规划→执行→诊断→回写"闭环。

> 📌 大促后**诊断与归因**请转 `method-ecommerce-ops` 的 M6（`campaign-diagnostic.md`）——那是用研究/诊断方法处理「为什么没达目标」，与本 playbook 的「怎么打」前后衔接但不混用。
