🗺 飞书原生卡片落地映射（哪些能 1:1 实现）
方案原生可实现落地方式
S1 / S8 / S11 文字行完全可note 元素 + lark_md 链接 + 回调按钮文字化；来源、👁（阅读数）、赞全并进一行 note。
S3 单行工具条完全可hr + lark_md（左链接）+ button(default, 紧凑)（右赞）——推荐默认方案。
S4 胶囊 / S5 幽灵近似可飞书按钮无胶囊/描边形态，用 default 类型小按钮 + 缩短文案近似；视觉略重。
S6 角标 / S7 徽章近似可角标可塞进 header 的 title 尾部或 fields 短列；徽章可用 emoji + 文本模拟，无真 chip 组件。
S9 悬浮显现不可飞书卡片不支持 hover 态，仅网页端/内嵌页可用。
S10 圆钮 / S12 footer近似可圆钮无原生形态；footer 可用 hr + 蓝色 note + 按钮行拼出「色带分区」效果。
通用减重原则通用① 计数只出现一次（融进按钮）② 来源降为 note 灰字 ③ 主按钮文案 ≤ 4 字 ④ 每条结论的操作区高度 ≤ 正文两行。
操作区样式看板 · 输出于 output/lark-action-styles.html · 配色与 output/lark-card-gallery.html 同源（雾色系）
👁 = 阅读数（随卡片曝光自动累加、无需点击）；各卡已统一移除「点击」计数，保留原有「打开链接 / 阅读原文」入口。点击标题 / 打开链接 / 赞可试交互反馈；选型后按映射表落到飞书卡片 JSON。
