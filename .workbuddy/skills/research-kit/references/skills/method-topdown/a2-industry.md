# A2 行业：谁真赚到钱 —— 产业链分层 + 兑现度矩阵

> 来源：2026-10-30 合并。原顶层 `research-industry`（旧 Track A 第二段）实战内容并入本文件，与套件原摘要合并去重。

## 方法与骨架的对应

骨架 D2「分层分解与度量」在本段的具体答法：**沿产业链拆成互斥且完备的环节，逐环节度量"兑现度"**。
本段回答「这条链谁真赚到钱、赚的是周期还是成长、什么时候会反噬」，再交 A3 落到单个标的。

## 两步走

### Step 1 · 拆环节（产业链分层 + 水位差）

按 **国产化率 / 技术代差 / 附加值**做**三级梯队**，指出"水位差"：

| 层级 | 赛道 | 国产化率 | 状态 |
|---|---|---|---|
| 第一梯队 | XX | >70% | 完全自主、全球竞争 |
| 第二梯队 | XX | 20–25% | 批量替代，已兑现 |
| 第三梯队 | XX | 个位数 | 未来三年主战场 |

典型环节参照：上游原料 / 设备 / 制造 / 渠道 / 应用 / 回收（按行业实际增删）。

### Step 2 · 逐环节过六问

| 问 | 回答什么 | 必须拿到的证据 |
|---|---|---|
| ① 需求侧 | 需求是真的吗？ | 下游客户**资本开支**、下游**收入增速**、出货 / 用量数据 |
| ② 供给侧 | 紧张到什么程度？ | **量**（产能/产量/出货）、**价**（涨价幅度/ASP）、**产能利用率 / 新建产能** |
| ③ Why now | 为什么是现在？ | **2–3 条同时发生**的驱动，缺一不可；写成可证伪的组合 |
| ④ 玩家地图 | 每环节谁在赚钱？ | 逐环节 **H1 营收 / 同比 / 归母 / 同比** 表；标出**真正盈利的家数** |
| ⑤ 估值 | 贵不贵？ | comps spread（**含口径声明**）+ Outlier 标记 |
| ⑥ 兑现度 | 真赚到了吗？ | **收入增速 × 现金流质量（净现比 + 合同负债）** |

**贯穿全篇的一根线 = 兑现度**。每个环节回答「兑现 / 半兑现 / 未兑现」，最后汇总成《兑现度矩阵》——这是本段区别于普通行业综述的关键产出。

| 环节 | 兑现度 | 关键证据 | 备注 |
|---|---|---|---|
| 光模块 | 真兑现 | H1 净利 +241.7%，订单覆盖到 2028 | 业绩弹性最大 |
| 存储 | 周期×成长 | DRAM 营收 +385%，但公司自认需求降温有波动风险 | **不是纯成长** |

## 硬规矩

1. **需求必须被财报或订单证实**——拿不出客户资本开支 / 收入增速 / 出货量任一项，标 `confidence: low`。
2. **必须区分"周期"与"成长"**（存储 / 面板 / 航运类尤其重要）。
3. **必须做环节分层**：行业内部从来不是齐步走。
4. **收入增速必须配现金流质量**，否则视为「纸面景气」。
5. **估值表必须声明口径**（第三方测算 / 一致预期 / 公司指引），混用即废。
6. A股 色规：▲红=涨、▼绿=跌，货币 ¥。

## 门禁（对应骨架 D2）

- 锁定 **1–3 个**兑现度最高的细分环节，方可进入 A3。
- 识别最需警惕的组合（如"估值最高 + 增速斜率最平"）。

## 口径登记（G4 必填）

- 净现比分母用「归母净利润」还是「扣非」须登记。
- 合同负债含预收款，须剔除季节性（如地产 / 军工）。

## 反方论点（≥2 条沉淀至此段，建议全过）

- **时间维度的失效点（最重要）**：驱动何时减速？增速何时从三位数掉到两位数？有无权威**下一年**预测？
- **客户的钱够不够**：下游是"想投"还是"投得起"？看下游**自由现金流**是否已净流出。
- **估值分位**：PE/PB 历史分位 >90%？与历史抱团终局的分位对比。
- **筹码与波动**：看**区间振幅**而非只看 YTD；有无单日踩踏先例。
- **业内分歧**：有无知名机构 / 基金经理公开相反观点？引原文。
- **周期回摆**：本轮景气已走几个季度？历史完整景气一般多长？机构预测何时见顶。
- **政策与地缘**：关税 / 管制是否扩大到终端品？二阶三阶环节（设备 / 材料）薄弱带在哪。
- **高增速环节可能产能过剩**，毛利率将快速坍缩。
- **合同负债高增也可能是渠道压货**（虚假需求）。
- **景气顶点的行业，兑现度矩阵会滞后反映拐点**。
- **Outlier**：「高估值 + 低斜率」「高利润 + 负现金流」「业绩爆发 + 高管减持」。
