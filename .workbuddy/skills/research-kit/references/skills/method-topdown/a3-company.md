# A3 公司：落到标的 —— 五段式 + 分子/分母三分法

> 来源：2026-10-30 合并。原顶层 `research-company`（旧 Track A 第三段）实战内容并入本文件，与套件原摘要合并去重。

## 方法与骨架的对应

骨架 D3「择优与失效检验」在本段的具体答法：**落到这只票，判断"杀的是估值还是基本面 / 贵得有没有道理 / 什么时候被想起"**。

## 五段式拆解

| 段 | 回答什么 | 必须拿到的证据 |
|---|---|---|
| ① 业绩侧 | 基本面好不好？ | 最近报告期**营收/归母/扣非/经营现金流/ROE/EPS** 同比表 + **业务拆分（第二曲线）** + 现金流质地（**单季净现比序列** / 收入现金比 / FCF） |
| ② 分子的裂缝 | 哪里有真伤口？ | **毛利率 ≥3 季趋势**、**合同负债**方向、存货/预付款/应付债券/资产负债率变动、**经营现金流增速 vs 利润增速**背离、**单季净现比斜率** |
| ③ 估值与资金 | 被定价的是什么？ | 三口径 PE（动/TTM/静）+ **前瞻 PE（标机构家数）**、区间涨跌与振幅、**估值压缩幅度**、**相对收益 vs 指数/行业**、同期资金流向、**卖方 vs 买方 vs 公司**三方行为表 |
| ④ 同业与叙事 | 市场在定价什么？ | **同日横截面表**（营收/归母/经营现金流/净现比/PE/资金）→ 提炼一句**可复用的判别原则** |
| ⑤ 三分法定性 | 所以怎么定性？ | 估值部分 / 基本面部分 / 时间部分 各一行判断 + 依据 + **下一个验证点（日期）** |

**贯穿全篇的一根线 = 分子 vs 分母**。每个证据都要归边——属于「分子（业绩）」还是「分母（估值/叙事/时间）」，最后汇总成三分法表。

## 三分法结论表（核心产出）

| 部分 | 判断 | 依据 | 下一个验证点 |
|---|---|---|---|
| 估值压缩部分 | 属于**叙事错杀** | <财务证据 + 前瞻 PE 测算> | — |
| 基本面部分 | 存在**真实边际转弱** | <裂缝证据> | Q3 报（10 月） |
| 时间部分 | **不确定性无法在本季度消除** | <需待 X 验证> | 1Q27 排产（2027-04） |

首行必须给明确定性：**错杀 / 部分错杀 / 非错杀** 三选一，不允许只描述不判定。

## 硬规矩

1. **先分清"杀估值"还是"杀基本面"，用三分法分开定价**——混为一谈会在两个方向上都做错。
2. **下跌 ≠ 错杀。必须主动找分子的裂缝**；找不到才允许下"错杀"结论，且标 `confidence: medium`。
3. **现金流质量是硬门槛**：净现比 / 收入现金比 / 自由现金流。**收入增速必须配现金流**。
   且**必须拆到单季**——半年度汇总会掩盖斜率恶化（CATL 回跑教训：H1 净现比 139% 优秀，拆开是 Q1 162% → Q2 118%，环比 -44.7pct）。
4. **必做同业横截面对照**：判断市场定价的是**财务质地**还是**叙事稀缺性**。
5. **必须做相对收益对照**：个股 ▼-8.64% vs 创业板指 ▲+1.52%，相对 -10.16pct。
   不做这步，会把**赛道级资金再分配**误读成个股崩塌，或反之把个股问题赖给大盘。
6. **三方行为交叉验证**（卖方评级 / 买方持仓 / 公司自身动作），背离要明写「说的 vs 做的」。
7. **口径异常登记不结论**：数据源打架（AH 倒挂、分部成本同比与整体毛利率趋势矛盾）时标 ⚠️ 进 queue，**不据此下结论、不替数据源圆场**。
8. **至少 1 条时间维度的反方论点**：回答"这个不确定性什么时候能被消除"。
9. A股 色规：▲红=涨、▼绿=跌，货币 ¥。

## 财务质量检查清单（写 ② 时逐项过）

- [ ] **毛利率**：连续几季？环比 + 同比各跌多少 pct？趋势性还是季节性？
- [ ] **净现比**（经营现金流 / 归母净利）：<100% 需解释；**趋势比绝对值重要**；**必须拆单季**
- [ ] **收入现金比**（销售商品收到现金 / 营业收入）
- [ ] **合同负债**：较年初 / 较上期的**方向**（订单能见度的领先信号）
- [ ] **存货增速 vs 收入增速**：备货激进还是滞销？有无计提减值
- [ ] **应收增速 vs 收入增速**：放宽信用换收入？
- [ ] **经营现金流增速 vs 归母增速**：背离即利润质量边际转弱
- [ ] **有息负债 / 应付债券 / 资产负债率**：是否为增长在加杠杆垫资
- [ ] **自由现金流**（经营 CF − 资本开支）：扩张期公司此项天然偏低
- [ ] **筹码结构**：股东户数变化、融资余额、限售解禁时点
- [ ] **口径一致性自检**：分部成本 / 收入同比 与 整体毛利率趋势是否打架？

## 口径登记（G4 必填）

- PE 用静态 / 动态 / 前瞻须登记（前瞻 PE 依赖一致预期）。
- 相对收益基准（沪深300 / 申万行业指数）须登记。

## 反方论点（≥1 条时间维度沉淀至此段）

- **硬反方（最重要）**：有没有一条负面证据**不能用"杀估值/风格切换"解释**？若有，便宜的 PE 是建立在会下滑的盈利之上。
- **时间维度**：核心不确定性**什么时候**才能被消除？在此之前有几个季度无法证伪？写出验证日期。
- **历史估值分位在利率范式切换时失效**（时间维度）。
- **龙一估值溢价可能压缩**（份额见顶）。
- **单季净现比波动受营运资本扰动**，需多年平滑。
- **订单端领先信号**：合同负债方向是否与"需求爆发"叙事冲突？
- **现金流 vs 利润背离**：是否在为增长垫资？
- **说做不一**：卖方 100% 买入 vs 买方减仓 vs 公司回购——历史上哪一方滞后？
- **资金逻辑双向适用**：因"故事轮换"而来，也会因"新故事更热"继续走。
- **口径陷阱**：PE 三口径差异、AH 溢价、币种折算、并表范围——异常项登记不结论。
- **Outlier 组合**：高利润 + 负现金流 / 高估值 + 低斜率 / 业绩爆发 + 高管减持。

## 建议监控项（回写 monitors，含阈值）

## 模板回跑（recheck）约定

- **触发**：新模板（或模板大改）首次应用于已有标的时，对旧版做一次回跑，产出 `v<n+1>`。
- **约束**：**数据窗口不变、不新增外部抓取**——增量只能来自"模板要求而旧版缺失的项"；确需补数进 queue，不现场编。
- **frontmatter**：加 `supersedes: <上一版文件名>`，`reason` 写明"按模板回跑"。
- **附录必须有**：`模板自检` 表——① 模板逼出的新发现 ② 仍缺的数据项（进 queue）。
- **回跑后回灌模板**：把自检结论修回本文件。**模板是用出来的，不是写出来的**。
- 首次回跑实证（2026-09-20，CATL v1→v2）：逼出 4 项旧版遗漏——单季净现比（162%→118%）、相对收益（-10.16pct 负 alpha）、前瞻 PE 入表、营业成本口径冲突；暴露 3 项数据缺口（应收 / 资本开支 / 筹码）。
