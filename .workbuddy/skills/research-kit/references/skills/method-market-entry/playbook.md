# 市场进入打法细则（E1–E5）

> 来源：2026-10-30 合并。原顶层 `research-market`（旧 Track B）实战内容并入本文件。

## 何时用 / 何时不用

**用**：目标是一个**具体国家 / 平台 + 具体行业**，目的是理解市场结构、准入、玩家格局。
**不用**：目的是在国内选交易标的 → 走 `method-topdown`（drill）；目的是诊断已有经营对象为何偏离 → 走 `method-ecommerce-ops`（diagnostic）。

## E1 · 国别 / 平台环境 + PEST

必取：GDP、人均 GDP、实际增速、CPI、失业率、人口规模与结构（中位数年龄 / 世代占比）、家庭收入中位数与分布（基尼 / 收入分层）、消费占 GDP 比重。

PEST 四维各写 1–2 条**可验证**的判断（不写套话）：

- **P** 政治 / 监管：谁能发牌照、哪个机构管、最近一次立法 / 执法事件
- **E** 经济：购买力、利率环境（对收租型商业模式的影响）、汇率
- **S** 社会：人群结构、信任水平、对新事物的接受度
- **T** 技术：基础设施、渗透率、支付方式

**判别点**：本段必须回答一句话——**"这个国家/平台的消费者，为什么现在会需要这个东西？"**

准入审查须先于需求分析（准入不过，需求再大 = 零）。

## E2 · 目标行业

- 规模与增速：**标注口径与 as-of 日期**；不同数据源冲突要**并列，不取平均**。
- 监管框架：**已生效 / 已通过待生效 / 悬而未决** 三档分开写。
- 价值链：谁收租、收的是什么租（利差 / 手续费 / 订阅 / 清算费）。
- 集中度与关键风险（如"两家占 85% 供给"）。

## E3 · 相邻 / 替代（本 Track 的关键增量）

问三个问题：

1. 这个国家 / 平台有没有**被禁止或受限的相邻品类**？（例：美国零售 CFD 非法）
2. 如果禁了，需求**被重定向到哪**？（例：CME 微型期货 / 期权 / 预测市场）
3. 承接方因此获得了什么？（合规溢价、定价权、机构资金入口）

> **这是最有价值的一步**：结构空白往往不是"没需求"，而是"需求被挤到了别处"。

## E4 · 用户画像 / 需求

至少覆盖七项：规模与渗透率、性别、年龄 / 世代、收入、地区、职业、用途与频次。
外加两项定性：**信任与顾虑**（信任谁、怕什么）、**支付 / 入金方式**。

**判别点**：把"渗透率"拆成 `持有率 × 客单价 × 频次`。高渗透 + 低客单价 = 小额高频，商业模型完全不同（靠频次与交叉销售，不是靠 AUM）。

## E5 · 主要 players + 财务对照

分层列：原生上市 / 原生未上市 / 传统机构 / 基础设施。
上市的必须做**同口径**财务对照表（营收 / 增速 / 净利 / 净利率 / 现金流 / 估值）。
**不可用同口径比较的要明确标注**（如交易所全口径 vs 纯加密收入）。

## 输入 / 输出契约

- **输入**：目标国 / 平台 + 目标行业（用户指定）+ 可选特定关注点。
- **输出**：笔记落 `archive/raw/<type>/`，命名 `<日期>_<type>_<主题>_v<版本>.md`；结构化数据同目录同名 `.csv`。
- **frontmatter 必填**：`source / url / fetched_at / type / structure / confidence`；可选 `tags / keywords / reason / project`。
- 落盘后跑 frontmatter 校验（命名与字段遵循 `file-manager` 规范）。
- 结论回写**本项目** `research/<PID>/research-state.yaml`；跨项目方法论提升到 `research/_shared/`（注：skill 级交付标准如 `references/rules/report-rubric-v1.md` / `delivery-standard.md` 已归位到本套件 `references/`，`_shared/` 仅用于项目层方法论文档，二者不混放）。

## 强制反方论点（≥5 条，至少 1 条时间维度）

1. **监管时间轴**：核心法案悬而未决 → 合规成本是浮动的（时间维度）。
2. **收入本质是某种 β**：如稳定币收入 = 利率 β，降息即杀。
3. **集中度风险**：前两名占多少，出事会怎样。
4. **流量 / 需求已见顶**：如 ETF 连续 N 季度净流出。
5. **成本刚性**：收入下滑时费用下不来（经营杠杆反向）。
6. **口径陷阱**：不同来源数字冲突，哪个可信。

## 交付物

机会区 / 禁区 / 观察哨清单 + 玩家地图（份额 + 护城河 + 商业模式）。
