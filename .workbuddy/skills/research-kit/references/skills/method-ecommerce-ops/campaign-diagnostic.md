# method-ecommerce-ops · 大促专项诊断（campaign-diagnostic）

> 本文件是 `method-ecommerce-ops`（diagnostic 的电商域实现）在**大促后复盘诊断**语境的细化打法。
> 它**不另起炉灶**：大促诊断 100% 复用主技能的 M2–M5（渠道/流量/漏斗/货品主播）+ R1–R2（根因/修复），只是叠加**大促特有的口径畸变与归因坑**。
> 对应主技能模块：**M6 大促专项诊断**。
>
> **与「大促策划/执行」的边界**：本文件只解决「已有一次大促完整数据，找为什么没达/超额达成、哪环节出问题」。怎么策划大促（货品矩阵、定价架构、蓄水节奏、直播排期）**不属本研究方法**，见独立运营 playbook。

---

## 一、适用与边界

- **触发**：一次大促（双11 / 618 / 双12 等）已结束，拿到三平台完整过程与结果数据，需诊断战果、定位缺口、归因、给出下场改进。
- **不触发**：还在策划期（无数据）→ 走运营 playbook；单纯做战报罗列无归因 → 退回 DG1 门禁（落差不可量化不许拆解）。
- **口径基线**（沿用主技能 M1，大促期须重设）：大促期自然占比会畸变（蓄水靠付费、爆发自然暴涨），**不能用常态"自然>50%"基线**；GMV 含预售定金+尾款跨期；退货在大促后 15–30 天才显现。

## 二、输入契约（G4 前必须齐）

| 输入 | 说明 |
|---|---|
| 三平台大促总览 | GMV / 订单量 / 客单价 / 转化率 / 广告花费 / ROAS / 店铺评分 / 退货率（含退款后净口径） |
| 货品结构 | 引流/利润/活动/形象四款的实际 GMV 占比与净毛利 |
| 直播数据 | 观看 UV / 停留 / GPM / 支付转化 / 退款后净 GMV / 主播分布 |
| 目标基线 | 大促前定的 GMV / ROAS / 毛利红线 / 复购率目标 |
| 过程指标 | 预热期收藏加购率、定金支付率、爆发期小时级 GMV、返场转化率 |

> 跨平台对比前必须先折算口径（见主技能「关键口径」）；口径未登记直接对比 = G4 不通过。

## 三、七步诊断法（复用 M2–M5 + R1–R2）

### 1. 战报 vs 目标（复用 M2 渠道对比 + 主技能 DG1）
- 分平台、分款类（引流/利润/活动/形象）算达成率，定位缺口在**哪个平台 / 哪类款**。
- 输出：达成率总表 + 缺口归因初判（是规模没起量，还是效率掉，还是毛利击穿）。

### 2. 分渠道 ROI 与毛利瀑布回填（复用 M3 流量结构 + 主技能 DG2）
- 每款回填毛利瀑布：出厂价 → 平台扣点 → 推广费 → 物流 → 佣金 → 活动让利 → 净毛利。
- **大促特有**：多券叠加（定金膨胀+满减+品类券+店铺券）是否击穿净毛利红线；拼多多低毛利是否靠走量摊薄（净毛利须仍 >0）。

### 3. 货品结构健康度（复用 M5 货品组合）
- 引流款是否过度吸血（靠亏毛利引流却没接住利润款转化）；利润款占比是否达 40% 目标。
- 活动款是否只冲了排名却亏损；形象款是否纯浪费资源。

### 4. 流量结构复盘（复用 M3，叠加畸变校正）
- 区分蓄水期（付费依赖常态）vs 爆发期（自然暴涨）的占比，避免误判"自然占比低=亚健康"。
- 识别"付费依赖型虚胖"：爆发期 ROAS 靠临时加投堆量，停投即塌。

### 5. 直播贡献诊断（复用 M5 主播矩阵）
- 核**退款后净 GMV**（直播 GMV 含刷单/退款虚高）；GPM、观看 UV、支付转化是否达标。
- 主播单点依赖风险：GMV 是否高度集中在 1–2 位主播。

### 6. 退货归因树（对应 R1 根因假设）
- 退货率拆因：保质期/临期预期落差 / 描述不符 / 物流时效 / 低价预期落差 / 质量问题。
- 每条假设须写"验证证据 + 可证伪条件"。

### 7. 复盘产出（对应 R2 验证与修复）
- **根因诊断书**（含证据链）+ **修复优先级矩阵**（影响 × 成本 → P0/P1/P2）。
- **3 条可复用经验 + 3 条下场改进**，回写本方法基线。
- 异常指标（净毛利红线、自然占比基线、T+30 退货率阈值）回写 `monitors` 带阈值，防复发。

## 四、大促特有口径坑（G4 必登记）

| 坑 | 表现 | 后果 |
|---|---|---|
| 跨期定金尾款 | 预售定金记本期、尾款跨月；GMV 口径切换 | 伪涨幅 / 伪落差 |
| T+30 退货滞后 | T+7 看退货率偏低，实际 30 天后才暴露 | 误判达标 |
| 直播退款虚高 | 直播 GMV 含大量退款/刷单 | 渠道贡献被高估 |
| 多券叠加击穿 | 优惠计算器未锁红线 | 卖越多亏越多 |
| 跨平台比价 | 拼多多低价拖累天猫价盘 | 品牌价盘失守 |

## 五、反方论点（大促专项，G4 强制 ≥5，含 1 条时间维度）

1. **GMV 涨 ≠ 健康**：大促 GMV 涨可能是付费堆量击穿毛利，须看净毛利而非 GMV。
2. **返场稀释主促**：返场低价可能提前透支需求、拉低整体毛利结构，需拆主促 vs 返场。
3. **直播 GMV 虚高**：含退款/刷单，退款后净 GMV 才是真贡献。
4. **跨期口径失真**：定金尾款跨期、退货滞后，T+7 战报与 T+30 复盘结论可能相反。
5. **时间维度**：大促 ROI 不能在平稳期复现——爆发期自然流量红利与平台流量倾斜不可持续，下场若按此 ROI 定预算会超投（历史大促效率在平常日失效）。

## 六、交付物与回写

- 分平台/分款类**大促诊断书**（战报 vs 目标 + 缺口归因）+ 修复优先级矩阵 + P0/P1/P2 清单。
- 货品结构健康度 + 直播净贡献 + 退货归因树。
- 全部结论落 `research-state.yaml` 的 `claims`；净毛利红线 / 自然占比基线 / T+30 退货率阈值回写 `monitors`（带阈值告警）。
