# method-sector-momentum — 行业景气度横截面跟踪（drill 的行业监测实现）

> 本技能是 `research-track-drill`（下钻选优**通用骨架**）在**行业景气度监测**语境的固化打法。
>
> **与骨架的分工（不重复）**：
> - 骨架 = 业务中立的推理过程：怎么定全集、怎么分解、怎么择优、怎么验失效（`在哪里分解`）。
> - 本技能 = 行业监测域的具体答法与口径：看哪两维、用什么代理、怎么交叉、什么算脉冲（`用什么算`）。
>
> 骨架里没有、也不该有「主力净流入 / 申万一级 / 月度环比 / 归一化基准 / β 剥离」这类术语——它们属于本层。

## 适用场景

- 「近一周资金净流入 Top10 行业有哪些」
- 「近一年行业月度景气度如何 / 画景气度热力图」
- 「哪些行业资金与景气双高 / 哪些是脉冲」
- 周频或月频**重跑式**行业监测（如需跨会话续做，可回写 `monitors`；**状态机为可选复用层，非必写**，见证据链精简方案 v1.1 §3.4）

## 与 method-topdown 的关系（父子，非包含）

| 技能 | 推理纵深 | 交付形态 |
|---|---|---|
| **本技能** | 停在**行业层横截面** | 行业景气图谱 + 四象限 + **行业短名单** |
| `method-topdown` | A1 宏观 → A2 行业 → A3 **公司** | **标的短名单** |

- 只做行业监测 → **本技能跑完即交付**，不下钻公司。
- 要做完整景气链 → **先跑本技能**出行业短名单，把名单交给 `method-topdown` 的 A3 继续下钻。
- 二者**不可混跑**：本技能不输出标的，`method-topdown` 不做横截面扫描（铁律 #3）。

## 启用方式

- **按语境按需加载**：drill 任务语境契合「行业景气度监测」时自动加载本技能；非行情场景（选平台 / 选渠道 / 选人群）不加载，由 research-core 回退到 drill 通用骨架。

## 分析任务清单（M0–M5 采集 + R1 检验）

### M0 定全集与口径基线（对应 D1 前半）

- **输入**：行业分类标准（默认**申万一级**，31 个）、分析窗口、重跑频率。
- **动作**：
  - 锁定行业全集与分类标准版本（申万 / 中信 / 通达信**口径不同，不可混用**）。
  - 注册**两套代理指标**（本方法的核心约定）：
    - **资金面（当期）** = 板块主力资金净流入 —— 反映"钱现在往哪去"。
    - **景气度（中期）** = 板块指数月底收盘的**月度环比涨跌幅** —— 反映"市场定价对景气的边际投票"。
  - ⚠️ **必须显式声明**：景气度以**价格**为代理，**未纳入盈利 / 订单 / 产能等基本面景气**。这是本方法的固有局限，须写进交付物，不得默示为"基本面景气"。
- **输出**：行业全集表 + 口径登记表（分类标准 / 窗口 / 代理指标定义）。
- **门禁**：全集封闭、代理指标已定义 → 方可采集。

### M1 资金面横截面（对应 D1）

- **动作**：
  - 拉板块资金主力统计，排**净流入 Top10**，并**同时列出净流出侧**（平衡视角，防幸存者偏差）。
  - 概念板块层交叉验证（如"军民融合 +40 亿"佐证国防军工 +39 亿）。
  - 标注驱动事件（政策 / 国标 / 业绩 / 龙头新高）。
- **输出**：净流入 Top10 表 + 净流出对照表 + 概念层佐证 + 事件标注。
- **门禁**：**≥2 路独立证据**指向同一方向，方可下钻（防单源叙事）。
  - ⚠️ **「独立」的严格定义（2026-10-30 回跑修正）**：必须是**不同发布方 / 不同数据源**。
    **同一篇资讯里的行业层与概念层不算**——回跑实例：NeoData 返回 3 篇资金流稿，看似 3 源，
    实为**证券时报一家**（含「证券时报网」）同源转载，且均引 Wind，行业层 +39 亿 与 概念层 +40 亿
    出自同一句话。当时误判为「≥2 路独立证据，门禁通过」，**实为门禁被虚假满足**。
  - 未满足时：报告中**不得宣称门禁通过**，须标注「单源，待补独立验证」并进 `queue`。
- **数字溯源硬规矩**：叙述中出现的每个数字必须能在**原始返回正文**中检索到。
  查无出处的标 `[UNSOURCED]` 或直接删除——回跑实例：v1 的「全市场主力净流出约 500 亿」在原始返回中
  **根本不存在**，是凭印象写入，经数字溯源自检（叙述数字 vs 结构化 JSON 比对 + 宏观断言 vs 原文检索）后已删除。
  → 建议每轮做数字溯源自检：叙述数字 vs 原始返回正文 / 结构化 JSON 比对；可由脚本或人工核对（本项目未固化独立校验脚本，必要时在项目中临时生成）。
- **口径陷阱**：主流数据源的"板块资金主力统计"是**日频 T+1，无原生周度聚合**。若用户要「近一周」，默认给**最新交易日快照并明示口径**；要严格 N 日累计须**逐日拉取求和**（配方见 `data-recipes.md`）。
- **数值常常是下限（回跑实测）**：资讯源写法分两种——「获得逾 39 亿元」= 精确下限值；「也获得**超**亿元净流入」= 只知道 >1 亿，精确值未知。
  → 必须为每条资金流标注 `lower_bound`（精确 / 下限），**下限值不得与精确值同权排序**（回跑中煤炭、石油石化、公用事业、电力设备均为下限 1.0 亿，与国防军工 39 亿不可直接比大小）。
- **提取须按行业名定向匹配**：通用正则 `[\u4e00-\u9fa5]{2,6}` 会抓到「子遭主力资金」这类子串污染。正确做法：遍历已知行业名单，对每个行业名单独 `re.search(行业名 + r"[^，。]*?(?:获得逾?([\d.]+)亿元|净流出(?:逾|超)([\d.]+)亿元)")`。
- **必须记录当日大盘状态**（涨跌家数 / 指数 / 成交额），供 M4 扣避险成分用。

### M2 时序景气采集（对应 D2 · 第 1 维）

- **动作**：逐行业拉板块指数**月 K**，取**月底收盘**，算月度环比涨跌幅，覆盖近 12 个月。
- **输出**：`行业 × 月份` 的月度环比原始矩阵 + 采集日志（含失败重试）。
- **门禁**：每个行业 **≥10 个**有效月底点；**缺失月份必须标注**，不得静默跳过。
- **常见坑**：接口偶发省略某月月末（如 1 月），若不标注，下一列会被误读为单月涨幅（实为跨 2 月累计）。

### M3 景气矩阵与路径（对应 D2 · 第 2 维）

- **动作**：
  - **热力图**：行业 × 月份 的月度环比矩阵（A股色规：**涨红跌绿**）。
  - **归一化折线**：统一基准日（默认 2025-12-31 = 100）看全年路径。
  - **YTD 条形**：年初至今收益排序。
- **输出**：三张图 + 归一化基准日声明。
- **门禁**：基准日 / 单位（%）/ 缺失月处理方式均已登记；**YTD 与路径必须同时呈现**（YTD 会掩盖路径，见反方 #4）。
- **硬规矩**：**所有叙述性结论（谁赢谁输、涨跌幅数值）必须由数据脚本生成或经脚本校验**，不得凭印象手写——手写数字与计算值不符是本方法最高频的错误。

### M4 双维交叉四象限（对应 D2 · 收敛）

把 M1 的**资金流（当期）** 与 M2/M3 的**景气动量（中期）** 交叉，逐行业落象限：

| 象限 | 资金流 | 景气动量 | 解读 | 处置 |
|---|---|---|---|---|
| **双高** | 高 | 高 | 趋势确认，资金与定价共振 | 主推 |
| **脉冲** | 高 | 低 | 事件驱动、可持续性存疑 | 观察，标注失效触发条件 |
| **未兑现** | 低 | 高 | 景气已起但资金未至 | 候选，等资金确认 |
| **双低** | 低 | 低 | 趋势性走弱 | 规避 |

- **输出**：四象限归类表（含象限划分阈值与依据）。
- **门禁**：收敛到 **1–3 个**主推行业，方可进入 M5。象限可为空（如"未兑现"无人入选），**不得为凑数强行归类**。
- ⚠️ 本环节是**本方法的决策增值点**，不得省略。只给两张并列图表而不交叉 = 未产出结论，G4 不通过。

**划分规则（2026-10-30 回跑固化）**：
- 资金轴 = 主力净流入**方向**（正 / 负），不设幅度门槛（幅度差异可达 250 倍，用方向更稳）。
- 景气轴 = **近 3 个月累计涨跌幅**的正 / 负（近期趋势动量），**不用 YTD**——YTD 会被年初基数主导，掩盖当前斜率。
- 散点图展示时，资金轴用**符号平方根压缩**（`sign(v)·√|v|`），否则 -253 亿会把其余 11 个点压成一条线；须在图上注明刻度性质。

**⚠️ 大跌日修正（回跑 v2 最重要的发现）**：单日资金流的方向会被**避险属性**主导。回跑实例：2026-10-29 全市场超 4700 只个股下跌，当日资金流入 Top 里挤进 5 个"近 3 月下跌"的行业（国防军工 +39 亿但近 3 月 -4.8%）——那是避险承接，**不是趋势买入**。
→ **硬规矩**：做 M4 前必须先记录**当日大盘状态**（涨跌家数 / 指数涨跌 / 成交额），并在象限解读时交叉扣除避险成分。否则"脉冲"象限会系统性虚高。

### M5 归因标注与 β/α 剥离（对应 D3）

- **动作**：
  - 对主推行业标驱动事件（政策 / 国标 / 业绩 / 供需 / 龙头催化）。
  - **剥离 β 与 α**：判断是赛道级资金再分配（β）还是行业自身基本面（α）。
  - **同涨同跌检验**：若多个入选行业在同一窗口同步大幅波动，说明定价的是**同一个 β**，并非分散信号。
  - **量化做法（回跑固化）**：用各行业的**月度环比序列**算两两 Pearson 相关系数矩阵，输出 ① 相关矩阵热力图 ②「独立性排名」= 每个行业与其最相关对手的 ρ。
    - 判据：ρ > 0.75 视为定价同一 β（回跑实例：电子-通信 0.94、计算机-有色金属 0.94、煤炭-石油石化 0.91）；ρ 低 = 波动不同源。
    - ⚠️ **低相关 ≠ 值得配置**：只说明波动不同源（回跑中独立性最高的是公用事业 0.59，却属脉冲象限）。独立性只用于**检验分散度**，不作买入理由。
    - ⚠️ **样本量**：12 个月数据只有 9 个环比区间，ρ 噪声大；须在交付物标注「n=9，指示性」，边缘值（0.6–0.75）存疑。
- **输出**：归因表（每个主推行业一行：驱动 / β或α / 失效触发条件）。
- **门禁**：每个入选行业有归因，或显式标注「无归因（纯资金驱动）」。

### R1 反方与失效检验（对应 D3）

- 提 **≥5 条**反方论点（见下），其中至少 **1 条为时间维度**。
- 结论落 `research-state.yaml` 的 `claims`（带 `confidence` + `status`）—— **可选**：一次性 / 轻量任务可直接在报告中呈现「结论 + 反方 + 口径」，不强制登记状态机（见证据链精简方案 v1.1 §3.4）。
- 关键指标回写 `monitors`（带 `last` / `as_of` / 阈值）—— **可选**：仅月频重跑 / 跨会话续做时启用：
  - 各主推行业月度环比（跌破阈值告警）
  - 主推行业主力净流入方向反转
  - 象限迁移（双高 → 脉冲 为最强减仓信号）

## 关键口径（须在 G4 登记）

| 口径 | 定义 | 常见坑 |
|---|---|---|
| 主力净流入 | 大单+特大单净额，单位 ¥ 亿元 | 日频 T+1，**无原生周/月聚合**；单日快照不代表一周 |
| 近一周口径 | 默认取最新交易日快照；严格 N 日须逐日求和 | 未声明即混用 = 伪精确 |
| 月度景气度 | 板块指数**月底收盘**环比涨跌幅（%） | 用月内最高/最低会系统性放大 |
| 归一化基准 | 统一基准日（默认上年末）= 100 | 基准选在低位会放大后续涨幅，须声明 |
| YTD | 基准日 → 最新月末累计涨跌幅 | **掩盖路径**，须与归一化折线同时看 |
| 行业分类 | 申万一级（默认，31 个） | 申万/中信/通达信**不可混用** |
| 板块名映射 | 数据源对板块名的识别不稳定 | 查询措辞须带 fallback（见 `data-recipes.md`） |

> 口径未登记即对比 = G4 门禁不通过。

## 反方论点（G4 强制 ≥5 条）

1. **价格景气 ≠ 基本面景气** —— 月度环比只反映定价边际，未含盈利 / 订单 / 产能；可能只是估值扩张。
2. **【时间维度】单日资金流是快照，不是趋势** —— 日内反转、尾盘拉抬会失真；"近一周"窗口在事件驱动周与平淡周的可比性不同。**更关键的是**：大跌日（回跑实例：超 4700 只个股下跌）资金流被**避险属性**主导，流入 Top 里会挤进一批中期下跌的防御行业，看似"资金看好"实为避险承接——必须与当日大盘状态交叉解读（见 M4 大跌日修正）。
3. **幸存者偏差** —— 只列 Top10 流入会忽略流出侧的同量级信号（如电子 -253 亿），单边叙事必然偏乐观。
4. **YTD 掩盖路径** —— 同等 YTD 下，路径可以是单边上行也可以是冲高崩塌（实例：电子 YTD -1.7%，但年内归一化曾达 186 后回落），高低点择时结论完全相反。
5. **指数编制失真** —— 板块指数多为市值加权，龙头单票可绑架整个行业读数（如银行被四大行绑架）。
6. **事件脉冲不可外推** —— 国标/政策催化多为一次性重定价，不应线性外推为趋势。
7. **基准日选择偏差** —— 归一化起点落在低位/高位会系统性放大/缩小后续幅度。
8. **缺失月误读** —— 接口省略某月会使下一列变成跨月累计，被当作单月涨幅解读。

## 交付物

- 月度景气度热力图 + 归一化走势折线 + YTD 收益条形（**涨红跌绿**、¥ 货币）
- 资金流 Top10 / 流出侧对照表
- **四象限归类表**（本方法的核心决策产出）
- 归因表（驱动 / β或α / 失效触发条件）
- 结论与口径须在报告中**内联呈现**（数字锚点 + 口径块 + 反方≥5）；登记 `claims` / `monitors` 为**可选**（仅跨会话复用场景），见证据链精简方案 v1.1 §3.4

## 边界

- 仅用于「**行业层横截面监测与排序**」。
- 要下钻到**标的** → 本技能出行业短名单后转 `method-topdown` 的 A3。
- 要解释「**为什么涨 / 事件归因叙事**」 → 属**资讯/事件驱动**链路，走热点追踪类技能，**不是本技能职责**（本技能只做结构化横截面）。
- 要问「**能不能进这个市场**」 → `entry` + `method-market-entry`。
- 本技能负责**分析方法与结论**；报告渲染 / 可视化产出不在本技能职责范围（交付走 `output/` 约定）。
