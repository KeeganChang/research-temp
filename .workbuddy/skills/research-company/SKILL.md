# research-company — 公司深度调研子类

> `research` 大类下的**公司**子类，是 **Track A 景气链 Top-Down 的第三段**（macro → industry → company）。
> 模板：`archive/raw/公司/20260919_公司_宁德时代-资金面撤离重估_v1.md`（属项目 **P01 · 2026-09-19 行业热点观察**）。
> 与上游分工：**macro 回答"钱在哪"、industry 回答"这条链谁真赚到钱"，company 回答"落到这只票，现在被定价的是什么、错在哪"**。

## 何时用
- 行业/宏观研究已锁定方向，需要落到具体标的做可交易判断。
- 某只票出现**大幅回撤或大幅上涨**，需要判断"杀/涨的是估值还是基本面"。
- 需要给行业报告配一个**对照组**（如"高现金流低估值 vs 负现金流高估值"），验证市场究竟在定价什么。
- **不用**：目的是在国外看市场准入与玩家格局 → 走 `research-market`（Track B）。

## 铁律
1. **先分清"杀估值"还是"杀基本面"，用三分法分开定价**——估值部分 / 基本面部分 / 时间部分混为一谈，会在两个方向上都做错。
2. **下跌 ≠ 错杀。必须主动找分子的裂缝**：毛利率 ≥3 季趋势、合同负债方向、经营现金流增速与利润增速的背离。找不到裂缝才允许下"错杀"结论，且要标 `confidence: medium`。
3. **现金流质量是硬门槛**（跨项目方法论 `research/_shared` C-17）：净现比、收入现金比、自由现金流。**收入增速必须配现金流**，只有增速和订单指引会把资金引向账面富贵。
   **且必须拆到单季**：半年度汇总会掩盖斜率恶化（CATL 回跑教训——H1 净现比 139% 优秀，拆开是 Q1 162% → Q2 118%，环比 -44.7pct）。
4. **必做同业横截面对照**：把目标放进同日同市场的表里（谁在被买、谁在被卖、各自多少倍 PE），判断市场定价的是**财务质地**还是**叙事稀缺性**。
5. **必须做相对收益对照**：把个股涨跌与**同期指数 / 所属行业**并排（如"个股 ▼-8.64% vs 创业板指 ▲+1.52%，相对 -10.16pct"）。不做这一步，会把**赛道级资金再分配**误读成个股基本面崩塌，或反之把个股问题赖给大盘。
6. **三方行为交叉验证**：卖方评级 / 买方持仓 / 公司自身动作（回购、增减持）。出现背离要明写"说的 vs 做的"。
7. **口径异常登记不结论**：数据源打架（如 H 股 PE 高于 A 股的 AH 倒挂、**分部成本同比与整体毛利率趋势矛盾**）时标 ⚠️ 进 queue，**不据此下结论、不替数据源圆场**。
7. **至少 1 条时间维度的反方论点**：回答"这个不确定性什么时候能被消除"（如"需待 1Q27 排产验证"）。
8. **结论必须给出明确定性**：`错杀` / `部分错杀` / `非错杀` 三选一写在 §6 首行，不允许只做描述不给判定。
9. **A股色规：▲红=涨、▼绿=跌，货币 ¥**；不硬编码路径与私密信息（见 `AGENTS.md` 铁律）。

## 输入契约
| 项 | 说明 |
|----|------|
| 目标公司 | 名称 + 代码（A股/港股/美股） |
| 上游结论指针 | 来自哪份宏观/行业笔记、哪条 claim（填 `reason` 与 claims `evidence`）|
| 数据窗口 | 最近一个完整报告期（半年报/年报）+ 最新收盘，显式声明 |
| 驱动问题 | "杀的是估值还是基本面" / "贵得有没有道理" / "为什么一直在跌"（默认第一问）|
| 可选对照标的 | 2–4 家同日同业，用于横截面表（默认取同行业资金流向两端的代表）|

## 方法论：五段式公司拆解（核心）

| 段 | 回答什么 | 必须拿到的证据 |
|----|---------|--------------|
| ① 业绩侧 | 基本面好不好？ | 最近报告期**营收/归母/扣非/经营现金流/ROE/EPS** 同比表 + **业务拆分**（找出第二曲线）+ 现金流质地（**单季净现比序列** / 收入现金比 / FCF）|
| ② 分子的裂缝 | 哪里有真伤口？ | **毛利率 ≥3 季趋势**、**合同负债**方向、**存货 / 预付款 / 应付债券 / 资产负债率**变动、**经营现金流增速 vs 利润增速**背离、**单季净现比斜率** |
| ③ 估值与资金 | 被定价的是什么？ | 三口径 PE（动/TTM/静）+ **前瞻 PE（一致预期，标机构家数）**、区间涨跌与振幅、**估值压缩幅度**、**相对收益 vs 指数/行业**、同期资金流向（谁在流入它 / 谁在从它流出）、**卖方 vs 买方 vs 公司**三方行为表 |
| ④ 同业与叙事 | 市场在定价什么？ | 同日横截面表（营收/归母/经营现金流/净现比/PE/资金）→ 提炼一句**可复用的判别原则** |
| ⑤ 三分法定性 | 所以怎么定性？ | 估值部分 / 基本面部分 / 时间部分 各一行判断 + 依据 + **下一个验证点（日期）** |

**贯穿全篇的一根线**：**分子 vs 分母**。每个证据都要归边——属于"分子（业绩）"还是"分母（估值/叙事/时间）"，最后汇总成三分法表。这是本报告区别于普通公司点评的关键产出。

## 财务质量检查清单（写 §② 时逐项过）
- [ ] **毛利率**：连续几季？环比 + 同比各跌多少 pct？趋势性还是季节性？
- [ ] **净现比**（经营现金流 / 归母净利）：<100% 需解释；**趋势比绝对值重要**；**必须拆单季**（半年/年度汇总会掩盖斜率）
- [ ] **收入现金比**（销售商品收到现金 / 营业收入）
- [ ] **合同负债**：较年初/较上期的**方向**（订单能见度的领先信号）
- [ ] **存货增速 vs 收入增速**：备货激进还是滞销？有无计提减值
- [ ] **应收增速 vs 收入增速**：放宽信用换收入？
- [ ] **经营现金流增速 vs 归母增速**：背离即利润质量边际转弱
- [ ] **有息负债 / 应付债券 / 资产负债率**：是否为增长在加杠杆垫资
- [ ] **自由现金流**（经营 CF − 资本开支）：扩张期公司此项天然偏低，读分时留意赔率被低估
- [ ] **筹码结构**：股东户数变化、融资余额、限售解禁时点（解释"为什么便宜还不涨"的辅助项）
- [ ] **口径一致性自检**：分部成本/收入同比 与 整体毛利率趋势是否打架？打架就登记，别替数据源圆场

## 输出契约

落盘路径：`archive/raw/公司/<日期>_公司_<主题>_v<版本>.md`
结构化明细：同目录同名 `.csv`（frontmatter 用 `data_file` 指向）。

**frontmatter（必填）**
```yaml

keywords: [毛利率下滑, 净现比, 合同负债, 自由现金流]
reason: "承接 <上游笔记> 的 claim C-XXXXXXXX-XX —— <一句话承接关系>"
data_file: <同名 .csv>
claims_added:               # 可选，回写 research-state 的结论编号
  - C-20260919-14
```

**正文结构（模板，章节号固定）**

- **篇首固定块**：`数据窗口与口径声明` 表（财务窗口 / 行情资金窗口 / 主力资金口径 / PE 口径 / 币种）+ 本篇性质（首次调研 or 回跑）
- 0. 一句话结论（含"杀的是分子还是分母"）+ **上游 claim 校验结果**（承接哪条 claim、validated / falsified / 本篇新增哪几条）
- 1. 业绩侧：报告期财务表 + **业务拆分（第二曲线）** + 现金流质地对照表（**含单季净现比序列**）
- 2. **分子的裂缝**（逐条：毛利率趋势 / 合同负债 / 资产负债表变重 / 现金流与利润背离 / **单季净现比斜率**）+ ⚠️ 口径冲突项
- 3. 估值与资金：价格与估值（三口径 PE + **前瞻 PE（标机构家数）** + 估值压缩幅度）/ **相对收益 vs 指数与行业** / **资金流向与同期对立面** / **"说的 vs 做的"三方表** / ⚠️ 口径异常项
- 4. **同业横截面对照** → 提炼一句可复用的判别原则（跨项目可复用的另提升到 `research/_shared/`）
- 5. **反方论点（强制，≥5 条，其中 ≥1 条必须是时间维度的失效点）**；建议做成表，加一列「能否用杀估值解释」
- 6. **三分法结论表**：首行给明确定性（`错杀` / `部分错杀` / `非错杀`）+ 估值 / 基本面 / 时间 各行判断 + 依据 + 下一个验证点；附"一句话给团队"
- 7. 待验证（落入**本项目** `research/<PID>/research-state.yaml` 的 `queue`，带预期验证日期）+ **建议监控项表（写回 `monitors`，含阈值）**
- 8. 证据与出处（分层列：披露 / 行情与资金 / 研报 / 媒体 / 一致预期）
- **附录（仅回跑时需要）**：`模板自检` 表——逐项对照上一版，列出模板逼出的新发现与仍缺失的数据项

## 执行流程
1. **先跑 `script/load_context.py --project <PID>`** 加载项目状态机，确认上游 claim、已有数据集（避免重复抓数）
2. 取最近完整报告期财务 + 最新行情资金；按五段式检索：**业绩 → 裂缝 → 估值资金 → 同业 → 定性**
3. 过一遍**财务质量检查清单**，每条裂缝标注"能用风格切换解释吗"（不能解释的才是真伤口）
4. 做同业横截面表，提炼判别原则
5. 写 §5 反方论点，逐项过清单（见下）
6. 落 `output/` 暂存 → 用户确认 → 移 `archive/raw/公司/`
7. 跑 `script/validate_frontmatter.py` 校验
8. **回写本项目 `research/<PID>/research-state.yaml`**：新增 claims（带 evidence/data 指针）、monitors（毛利率拐点 / 合同负债 / 基金持仓 / 回购进度）、queue 补 Q 条目
9. 交 **wiki-skill** 抽实体建双链 → `archive/wiki/公司/` + 更新 `MOC.md`

## 反方论点清单（写 §5 时逐项过）
- **硬反方（最重要）**：有没有一条负面证据**不能用"杀估值/风格切换"解释**？（如毛利率三连降）若有，便宜的 PE 是建立在会下滑的盈利之上的
- **时间维度**：核心不确定性**什么时候**才能被消除？在此之前有几个季度无法证伪？明确写出验证日期
- **订单端领先信号**：合同负债方向是否与"需求爆发"叙事冲突？需要公司解释什么？
- **现金流 vs 利润背离**：经营现金流增速远低于利润增速意味着什么？叠加存货/负债变动，是否在为增长垫资？
- **说做不一**：卖方 100% 买入 vs 买方减仓 vs 公司回购——历史上哪一方滞后？目标价在下跌趋势中是否滞后下修？
- **资金逻辑双向适用**：既然因"故事轮换"而来，也会因"新故事更热"继续走；缺的是催化剂而非价值
- **口径陷阱**：PE 三口径差异、AH 溢价、币种折算、并表范围——异常项登记不结论
- **Outlier 组合**：高利润 + 负现金流 / 高估值 + 低斜率 / 业绩爆发 + 高管减持

## 模板回跑（recheck）约定
- **触发**：新模板（或模板大改）首次应用于已有标的时，对旧版做一次回跑，产出 `v<n+1>`。
- **约束**：**数据窗口不变、不新增外部抓取**——增量只能来自"模板要求而旧版缺失的项"。确需补数则进 queue，不现场编。
- **frontmatter**：加 `supersedes: <上一版文件名>`，`reason` 写明"按模板回跑"；沿用旧 CSV 时在正文注明"本篇未新增数据表"。
- **附录必须有**：`模板自检` 表——逐项对照上一版，列出 ① 模板逼出的新发现 ② 仍缺的数据项（进 queue）。
- **回跑后回灌模板**：把自检结论修进本 SKILL.md。**模板是用出来的，不是写出来的**。
- 首次回跑实证（2026-09-20，CATL v1→v2）：逼出 4 项旧版遗漏——单季净现比（162%→118%）、相对收益（-10.16pct 负 alpha）、前瞻 PE 入表、营业成本口径冲突；并暴露 3 项数据缺口（应收 / 资本开支 / 筹码）。
