# method-topdown — 景气链方法（drill track 的投资域实现）

> 本技能是 `research-track-drill`（下钻选优**通用骨架**）在**投资 / 资产选择**语境的固化打法。
>
> **2026-10 合并**：原独立的 `ashare` 域已并入本技能。
> **2026-10-30 再合并**：原顶层 `research-macro` / `research-industry` / `research-company`（旧 Track A 三段实战版）已并入本目录的 a1/a2/a3，不再与套件并行存在两份。
> A股 细化口径收在 a1/a2/a3 三个文件里，不再单列一层。

## 与骨架的分工（不重复）

- **骨架** = 业务中立的推理过程：`在哪里分解`。
- **本技能** = 投资域的具体答法与口径：`用什么算`。

「资金流向 / 兑现度 / 分子分母 / 多空」属于本层，通用骨架里没有、也不该有。

## 启用

- 当前 `enabled: false`：**不参与** research-core 自动路由（与「骨架默认启用、具体分析默认不启用」一致）。
- 启用：把 frontmatter 的 `enabled` 改为 `true`，本技能即作为 drill track 的投资域实现被调度。

## 三段与细则文件

| 骨架阶段（通用） | 本技能阶段（投资域） | 细则 |
|---|---|---|
> 三段细则均含：方法步骤 + 硬规矩 + 门禁 + 口径登记 + 反方清单 + 常用表格式 + 交付回写。

| 骨架阶段（通用） | 本技能阶段（投资域） | 细则 |
|---|---|---|
| D1 定总池与流向 | A1 宏观：钱在哪（多路资金交叉验证） | `a1-macro.md` |
| D2 分层分解与度量 | A2 行业：谁真赚到钱（产业链分层 + 兑现度矩阵） | `a2-industry.md` |
| D3 择优与失效检验 | A3 公司：落到标的（五段式 + 分子/分母三分法） | `a3-company.md` |

## 关键口径（须在 G4 登记）

- 资金流向须 **≥2 路独立证据同向**；收入增速须配现金流质量（净现比 + 合同负债）。
- 现金流须**拆单季**；须做**相对收益对照**（vs 指数/行业），否则易把赛道级资金再分配误判为个股崩塌。
- 各段自身口径（北向口径 / 净现比分母 / PE 口径 / 相对基准）见对应细则文件的「口径登记」。

## 反方（G4 强制 ≥5 条，含 1 条时间维度）

由三段各自沉淀后合计：**A1 ≥2 · A2 ≥2 · A3 ≥1**，且 A3 那条须为**时间维度**（如「历史估值分位在利率范式切换时失效」）。

## 交付物

宏观资金热力图 + 行业兑现度矩阵 + 标的短名单（含多空论点与相对收益）。
全部落 `research-state.yaml` 的 `claims`，并回写 `monitors`。

## 边界

- 仅用于「选资产 / 选标的」这类**可比较候选集**场景。
- 非投资场景（选跨境电商平台、选投放渠道、选细分人群）请直接用 drill 骨架 + 自定口径，**不要硬套财务指标**。
