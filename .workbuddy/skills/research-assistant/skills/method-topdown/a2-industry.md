# A2 行业：谁真赚到钱 —— 六段式产业链 + 兑现度矩阵

## 方法
1. 拆解产业链六段：上游原料 / 设备 / 制造 / 渠道 / 应用 / 回收。
2. 对每段评估：收入增速、毛利率、产能利用率、库存周期。
3. 兑现度矩阵：收入增速 × 现金流质量（**净现比 + 合同负债**）。

## 硬规矩
- 收入增速**必须配现金流质量**，否则视为「纸面景气」。
- 净现比 = 经营现金流净额 / 净利润；合同负债高增 = 订单先行。

## 门禁（对应骨架 A2）
- 锁定 **1–3 个**兑现度最高的细分环节，方可进入 A3。

## 口径登记
- 净现比分母用「归母净利润」还是「扣非」须登记。
- 合同负债含预收款，须剔除季节性（如地产 / 军工）。

## 反方（≥2 条沉淀至此段）
- 高增速环节可能产能过剩，毛利率将快速坍缩。
- 合同负债高增也可能是渠道压货（虚假需求）。
- 景气顶点行业，兑现度矩阵会滞后反映拐点。
