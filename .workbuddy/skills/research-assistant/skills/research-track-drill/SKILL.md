# research-track-drill — 下钻选优（Drill-down）

> 方法级 Track 之一（共 5 种：drill / entry / diagnostic / inductive / scenario）。只定义「问什么 / 门禁 / 交付形态」；怎么算、用什么口径，由 method 提供。
>
> **本骨架业务中立**：同一套下钻逻辑，既能选股票，也能选跨境电商平台、投放渠道、细分人群或 SKU。
> 通用阶段（D1–D3）**不预设任何领域口径**——「钱在哪 / 兑现度 / 多空」这类投资话术属于 method 层，见 `method-topdown`。

## 适用

目标：从「候选全集」逐层分解，筛选出最优的可行动单元。推理方向 = **演绎·总→分**。

判据（满足任一倾向 drill）：
- 问题能翻译成「全集里**哪个最好 / 最值得投入**」；
- 存在**可比较的同类候选**（能摆在一张表里横评）。

跨领域示例：选标的（投资）· 选平台（跨境电商）· 选渠道（投放）· 选人群（运营）· 选 SKU（产品）。

## 通用三段（每段带门禁）

### D1 定总池与流向
- 问题：候选全集是什么？当前资源 / 需求 / 注意力正流向哪个大方向？
- 门禁：≥ **2 路独立证据**指向同一方向，方可下钻（防单源叙事）。

### D2 分层分解与度量
- 问题：如何把总池分解成**互斥且完备**的子集？每个子集「好」用什么指标衡量（口径须统一）？
- 门禁：分解维度 + 度量口径已登记（单位 / 可比性 / 口径冲突处理），并收敛到 **1–3 个**最优子集。

### D3 择优与失效检验
- 问题：最优子集的优势凭什么持续？什么条件下会失效（可被推翻）？
- 门禁：给出短名单，每个单元附正面论点与**反面/失效论点**，并标明失效触发条件。

## 反方（G4 强制 ≥5 条，含 1 条时间维度）

由具体 method 沉淀；骨架不预设反方内容，但要求至少 1 条为**时间/周期维度**（为什么这次可能不一样）。

## 交付形态（与域无关）

- 总池 → 子集的分层清单（含互斥完备性说明）
- 各子集度量对比表（含口径说明）
- 最优单元短名单（含优势论点 + 失效触发条件）

全部落 `research-state.yaml` 的 `claims`，并回写 `monitors`。

## 边界（避免用错）

- 只在已有「可比较候选集」时用 drill。
- 问「为何变差 / 根因」→ diagnostic；问「能不能进 / 谁在赚」→ entry；问「未来会怎样」→ scenario。
- **未启用任何 method 时，只输出骨架级结论**，不得假装给出域具体数值。

## 接入

- 具体打法：`belongs_to_track: drill` 的 method skill（如 `method-topdown` 景气链；默认 `enabled: false`，须显式启用）。
