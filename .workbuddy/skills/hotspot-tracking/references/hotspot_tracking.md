# 热点追踪处理流程（上游）

本文件是 `hotspot-tracking` skill 的上游方法论：如何把「近一周 A股热点」从原始资讯变成一份可发布的研究笔记 + 信号源清单。下游飞书发布见 `SKILL.md` 与 `references/lark_commands.md`。

## 1. 触发与周期

- 触发语：「近一周 A股热点追踪」「这周市场在炒什么」「热点复盘」「帮我跟一下本周主线」。
- 频率：资讯日频、热点专题不定期（本次为专题）。属 `drill` 景气链下游的「市场温度」观察（资讯域，不入 vault 双链、只做发布视图）。
- 关联项目：默认 `project: P01`（行业热点观察）。

## 2. 数据来源与工具

- 资讯聚合：用「热点猎手」专家（aihot / 中文财经资讯聚合）或 `WebSearch` 拉取近一周财经热点、政策、产业事件。
- 资金面：板块资金净流入 / 净流出、主力资金（东方财富 / 同花顺 / NeoData `westock` · `neodata-financial-search` 的板块行情 + 资金流向）。
- 事件日历：公司审厂 / 新品、政策落地时点（如公积金新政施行日）。

## 3. 分析框架：两段式资金叙事

把一周拆成两段，用资金数据定调，避免「只列涨跌幅」：

- **主升段**：哪类板块资金大幅净流入（例：9/14-9/18 电子 +6%、净流入 324 亿）。
- **退潮切换段**：资金是否转向净流出、主力是否获利了结（例：9/21-9/24 电子净流出 302 亿、全周主力净流出 961 亿）。
- 结论句：科技主升 → 退潮切换；判断是否「增量资金驱动」还是「存量博弈 / 末端获利了结」。

## 4. 排名与活口

- 排 **Top3 主线**：按「资金强度 + 催化密度」排序（例：① 半导体 / 国产算力链 ② 光模块 CPO / 1.6T ③ 人形机器人 - 特斯拉审厂）。
- 标 **活口**：仍具持续催化的方向（例：机器人审厂 + 地产公积金新政 9/20 施行），用于区分「真主线」与「一日游」。

## 5. 交叉验证与反方

- 与既有研究互证（本次与 P03 芯片行业「价涨非量涨」互证）。
- 必给反方论点 + 时间维度失效点（如政策窗口、财报季、审厂结果时点）。

## 6. 输出契约

- **报告**：`archive/raw/热点/YYYYMMDD_热点_<主题>_v1.md`
  - frontmatter：`type: 热点`、`project: P01`、source / url / fetched_at 等（见 `file-manager` 与 `script/validate_frontmatter.py`）。
  - 正文：两段式叙事 + Top3 + 活口 + 交叉引用 / 反方。
- **信号源清单**（供下游飞书 Base）：每条 `标题 / 来源 / URL / 抓取日期 / 关键信号 / 关联项目`。
  - 若用户要求「URL 并入标题」，下游 Base 用 `[标题](url)` 可点击链接、并删独立 URL 列。

## 7. 下游衔接

报告与信号源清单产出后，直接进入 `SKILL.md` 的「飞书发布三件套」流程（Base / Doc / 群卡片）。
